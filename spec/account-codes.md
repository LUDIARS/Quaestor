## 仕訳生成ロジック

按分率 r、 取引金額 A、 コード c の取引について:

- `r > 0`: 借方 `c`(`A * r`) / 貸方 `102` 当座預金(`A * r`)、 残り `A * (1-r)` は 借方 `124` 事業主貸 / 貸方 `102` (摘要: `クレカ引き落とし調整`)
- `r == 0`: 借方 `124` (`A`) / 貸方 `102` (`A`)
- 現金支払の場合は貸方を `101` 現金 に置換
