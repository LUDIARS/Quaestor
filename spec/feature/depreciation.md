# 減価償却 (depreciation)

設計書: `spec/plan/2026-09-03-depreciation.md`。 実装が `@implements` で指す条項の正本。

## SPEC-DEPRECIATION-001 — 固定資産台帳と償却率表

- `fixed_assets` がエクセル簿記 ③ の 1 行 (名称 / 数量 / 取得年月 / 取得価額 / 償却方法 / 耐用年数 / 事業専用割合 / 摘要) に対応する。 償却額は保存せず年ごとに計算する。
- 償却率表はデータ (`rates.json`、 耐用年数 2〜50)。 旧定額 / 旧定率 / 定額 / 250% 定率 は 2025.xlsx 由来、 200% 定率は別表第十の転記。
- family は取得日から決める: 2007-03-31 以前は旧法、 2007-04-01〜2012-03-31 の定率は 250%、 2012-04-01 以後の定率は 200%。

## SPEC-DEPRECIATION-002 — 償却計算

- 本年中の償却期間は 取得年 = 取得月〜12 月、 除却年 = 1 月〜除却月、 それ以外 12 ヶ月。 取得前・除却後・完了後は 0。
- 定額: 取得価額 × 率 × 月/12。 定率: 期首簿価 × 率 × 月/12、 期首簿価 × 率 < 取得価額 × 保証率 になった年から改定取得価額 × 改定償却率。 いずれも備忘価額 1 円を残す。
- 旧定額 (基礎 = 取得価額 × 0.9) / 旧定率 (基礎 = 期首簿価): 取得価額の 5% まで償却し、 到達後は (5% − 1) ÷ 5 (切上げ) を年ごとに。
- 一括償却は 3 年均等 (月割なし)、 即時は取得年に全額。
- 経費算入額 = round(合計 × 事業専用割合)、 家計分 = 残り、 期末簿価 = 期首簿価 − 合計。 年度表の合計行は各列の和。

## SPEC-DEPRECIATION-003 — 仕訳計上と API

- 年度の計上は `借方 費用科目 (経費算入額) / 貸方 資産科目` と `借方 124 事業主貸 (家計分) / 貸方 資産科目` の直接法。 行は `asset_id` を持ち、 再計上で入れ替わる。
- 必要な科目 (18 減価償却費、 111〜116、 124 事業主貸) が無ければ account_codes に足す。
- API は `/v1/depreciation` (assets CRUD / projection / :year/schedule / :year/post / rates)。 耐用年数は定額・定率で 2〜50 必須、 期首簿価は年とセットで指定する。 資産を削除したときは、その資産から計上した仕訳も削除する。
