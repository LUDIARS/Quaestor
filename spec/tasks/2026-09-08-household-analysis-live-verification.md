# 家計分析の収支・貯蓄傾向・節制提案が稼働環境へ反映されていることを確認する

## 目的

家計分析の API・画面に追加した収入、支出、貯蓄率の傾向、節制候補について、
稼働中の Quaestor で利用できることを確認する。実装のレビュー結果だけでは、
配信中の画面と稼働プロセスへの反映は確定できない。

## 完了条件

- 本体 checkout と稼働プロセス・配信ファイルの関係を確認し、対象機能の反映状況を記録する。
- ユーザーの明示的なテスト実行許可を得た後、週・月・3ヶ月・6ヶ月・1年の切替で
  収入、家計・事業支出、収支差額、貯蓄率、月別推移が API と画面で整合することを確認する。
- 入金なし、支出記録なし、比較範囲の欠月、期間途中では評価保留と理由が表示されることを確認する。
- 振替の除外、事業支出を控除した収支、節制候補の支出額・件数・削減試算の表示を確認する。
- 家計の実データや個人情報をログ・外部通知に載せず、確認結果は Concordia の状態・結果記録に残す。

## スコープ (編集可ディレクトリ)

原則としてソース編集なし。Quaestor 本体の配信状態と実行環境の確認を対象にする。
不具合が判明した場合は原因と必要な修正範囲を別タスクに分解する。

## 実行条件

このタスクの保存はテスト・再起動・main 更新の許可ではない。ユーザーの明示許可なく実行しない。
起動・再起動が必要なら Concordia に事前 claim を登録し、Excubitor 経由で
プロジェクト本体フォルダからのみ操作する。worktree から起動せず、終了後に release する。
反映が確認できている場合は不要な再起動を行わない。
