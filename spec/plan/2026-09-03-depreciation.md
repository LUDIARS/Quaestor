# 減価償却の管理 — 設計書

作成: 2026-09-03 / 対象: Quaestor (Qs) / 状態: 実装済 (同 PR)。 前段: `2026-09-03-household-bookkeeping-analysis.md` (PR #1232) で対象外にしていた ③ を足す。

## 0. 依頼 (neco)

「減価償却も管理しよか」。 エクセル簿記の「③ 減価償却費の計算」シートに相当する台帳と計算を Quaestor に載せ、 仕訳帳・決算書 (PL の 18 減価償却費、 BS の資産期末) へつなぐ。

## 1. エクセル簿記 ③ の仕組み (2025.xlsx 解析)

1 資産 1 行 (B8:AD19)。 列の意味:

| 列 | 意味 | Excel の式 |
|---|---|---|
| B/C/D | 名称 / 数量 / 取得年月 | 入力 |
| G (イ) | 取得価額 | 入力 |
| I (ロ) | 償却の基礎になる金額 | 償却法別: 新定額=取得価額、 新定率=期首簿価 (改定後は改定取得価額)、 旧定額=取得価額×0.9、 旧定率=期首簿価 |

| N (ハ) | 償却率 | 償却率表 (EB8:EH56、 耐用年数 2〜50) を VLOOKUP。 新定率は 期首簿価×率 < 取得価額×保証率 なら改定償却率へ切替 |
| P (ニ) | 本年中の償却期間 (月) | 入力 (取得年は取得月〜12 月) |
| R (ホ) | 本年分の普通償却費 | (ロ)×(ハ)×(ニ)/12。 期首簿価 ≤ 1 なら 0、 計算額が期首簿価以上なら 期首簿価 − 1 (備忘価額 1 円)。 旧法は簿価が取得価額の 5% に達した後 (5%−1)÷5 を 5 年均等 |
| T (ヘ) | 割増 (特別) 償却費 | 入力 (今回は 0 固定で列だけ持つ) |
| U (ト) | 本年分の償却費合計 | R + T |
| V (チ) | 事業専用割合 (%) | 入力 |
| X (リ) | 本年分の必要経費算入額 | ROUND(U × V / 100) |
| Z (ヌ) | 未償却残高 (期末) | 期首簿価 − U |
| AC | 前年末の未償却残高 (期首簿価) | 前年ブックから引き継ぎ |

償却率表 (EB8:EH56) は 旧定額 / 旧定率 / 新定額 / 定率 (250%、 2007-04〜2012-03 取得) の 償却率・改定償却率・保証率。
決算書側は 18 減価償却費 (費用) と 111〜116 (建物 / 建物付属設備 / 機械装置 / 車両運搬具 / 備品 / 土地) の資産科目。

## 2. 方針

- **固定資産台帳** (`fixed_assets`) を持ち、 各年の償却は **純関数** で計算する (年の途中でも再計算可、 保存しない)。
- 償却法は 5 つ: 定額 (`straight_line`)、 定率 (`declining_balance`)、 旧定額 / 旧定率 (2007-03 以前取得)、 一括償却 3 年均等 (`lump_sum_3y`、 10〜20 万円)、 即時 (`immediate`、 30 万円未満の少額減価償却資産)。 新旧の判定と 250% / 200% の判定は **取得日から自動** (2007-04-01、 2012-04-01 が境)。
- 償却率表はデータ (`src/services/depreciation/rates.json`)。 旧定額 / 旧定率 / 定額 / 250% 定率 は 2025.xlsx から抽出。 **200% 定率 (2012-04 以降取得) は国税庁 別表第十 の値を転記したもので、 実データでの照合が要る** (率 = 2/n を 3 桁丸め、 改定償却率・保証率は表値)。
- 年末に **仕訳へ計上** する: `借方 18 減価償却費 (経費算入額) / 貸方 資産科目` と `借方 124 事業主貸 (家計分 = 合計 − 経費算入額) / 貸方 資産科目` (直接法。 エクセル簿記の ④ が資産の期末 = 期首 − 償却費 になっているのと同じ)。 仕訳行には `asset_id` を持たせ、 年単位で再計上できる (冪等)。
- 決算書 / 精算表は既存の仕訳帳ベースのまま。 資産科目の期首は `opening` に入れる運用 (前年末未償却残高)。
- Excel 簿記互換ブックに「減価償却」シートを足す (③ と同じ列)。

## 3. データモデル (migration v16 → v17)

### `fixed_assets`

| 列 | 意味 |
|---|---|
| id | PK |
| name | 名称 (B) |
| quantity | 面積又は数量 (C、 自由文) |
| acquired_on | 取得日 ISO (Excel は年月。 日は 01 でよい) |
| cost | 取得価額 (G) |
| method | `straight_line` / `declining_balance` / `old_straight_line` / `old_declining_balance` / `lump_sum_3y` / `immediate` |
| useful_life | 耐用年数 (L)。 lump_sum_3y / immediate は無視 |
| business_ratio | 事業専用割合 0..1 (V) |
| asset_code | 資産科目 (111〜116 等) |
| expense_code | 費用科目 (既定 18) |
| opening_book_value / opening_year | 台帳に載せた時点の期首簿価とその年 (AC)。 null なら取得年から全部計算 |
| revised_cost | 改定取得価額 (定率の切替時に確定した簿価)。 null なら計算で求める |
| disposed_on | 除却・売却日 (以降は償却しない) |
| notes | 摘要 (AD) |

`journal_entries` に `asset_id INTEGER` を追加 (ensureColumn)。 減価償却の計上行は `origin=manual` + `asset_id` で識別し、 年単位で消して入れ直す。

## 4. サービス (`src/services/depreciation/`)

| ファイル | 責務 |
|---|---|
| `rates.json` / `rate-table.ts` | 償却率表と family (`old_sl` / `old_db` / `sl` / `db250` / `db200`) の解決。 取得日と method から family を決める |
| `depreciation-calc.ts` | 1 資産 × 1 年の償却計算 (③ の R/U/X/Z) と、 取得年〜完了年の投影 (期首簿価・改定取得価額を年ごとに繰り越す)。 純関数 |
| `depreciation-schedule.ts` | 年度の全資産分の ③ 表 (台帳を読み、 各資産を投影して該当年の行を抜く) と合計 |
| `depreciation-posting.ts` | 年度の償却仕訳を journal_entries に計上 (asset_id 付き、 再計上で入れ替え)。 必要な科目 (18、 111〜116、 124) が無ければ account_codes に足す |

### 計算規則 (depreciation-calc)

- 本年中の償却期間 (月): 取得年は 取得月〜12 月、 除却年は 1 月〜除却月、 それ以外 12。 取得前 / 除却後 / 償却完了後は 0。
- 定額 (新): 基礎 = 取得価額、 普通償却費 = round(基礎 × 率 × 月/12)。 期首簿価 ≤ 1 → 0。 計算額 ≥ 期首簿価 → 期首簿価 − 1。
- 定率 (新、 250% / 200%): 基礎 = 期首簿価。 期首簿価 × 率 < 取得価額 × 保証率 になった年から 基礎 = 改定取得価額 (その年の期首簿価)、 率 = 改定償却率。 備忘価額 1 円は定額と同じ。
- 旧定額: 基礎 = 取得価額 × 0.9。 簿価が 取得価額 × 5% を超える間は min(計算額, 期首簿価 − 5% 価額)。 5% に達した後は (5% 価額 − 1) ÷ 5 (切上げ) を年ごとに、 min(期首簿価 − 1)。
- 旧定率: 基礎 = 期首簿価、 それ以外は旧定額と同じ 5% 規則。
- 一括償却 (3 年均等): 取得年から 3 年、 取得価額 ÷ 3 (月割なし、 最終年は残り全部)。
- 即時: 取得年に取得価額全額。
- 経費算入額 = round(合計 × 事業専用割合)、 家計分 = 合計 − 経費算入額、 期末簿価 = 期首簿価 − 合計。

## 5. API (`/v1/depreciation`)

| ルート | 内容 |
|---|---|
| `GET/POST /assets`, `GET/PATCH/DELETE /assets/:id` | 固定資産台帳 CRUD |
| `GET /assets/:id/projection` | 取得年〜完了年の投影 |
| `GET /:year/schedule` | その年の ③ 表 (資産ごとの行 + 合計) |
| `POST /:year/post` | 償却仕訳を計上 (再計上可) |
| `GET /rates` | 償却率表 |

## 6. 画面

`Depreciation.tsx` (タブ「減価償却」): 年セレクタ、 ③ 相当の表、 資産の追加 / 編集 / 除却、 資産ごとの投影、 「仕訳に計上」ボタン。
簿記ページのブック出力に「減価償却」シートが増える。
